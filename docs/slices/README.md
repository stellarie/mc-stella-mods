# Slice and feature branch docs

One implementation-and-design document per feature branch on `origin`. Each branch carries its own
document at `docs/slices/<name>.md`; the complete set is on `claude/practical-mayer-ewlb1h`. The
branch-to-slice map is in `HANDOFFS-2026-09-26.md`, section "Slice and branch map".

Every document was written from the branch's commits, their messages, and the current tree. Claims
about test counts and hashes are quoted from the commit messages or the handoff, which recorded them;
this session ran no Gradle command.
