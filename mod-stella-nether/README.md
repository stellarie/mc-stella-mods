# Stella Nether Raid

An instanced nether raid. The design is in `docs/plans/2026-09-28/NETHER-RAID.md`.

## Slice 0: scaffold

- The mod requires the rest of the modpack: mobs, equips and enchants, spells, villages, the tower and food.
  Gradle builds each from its sibling directory as an included build, so build from this directory with
  the siblings checked out beside it.
